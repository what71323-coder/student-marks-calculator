STUDENT MARKS CALCULATOR
=======================

PROJECT DESCRIPTION:
This project is a Student Marks Calculator developed
using HTML, CSS and Vanilla JavaScript.

FEATURES:
1. Enter student name.
2. Enter marks for five subjects.
3. Calculate total marks.
4. Calculate average marks.
5. Calculate percentage.
6. Display practice category.
7. Validate marks between 0 and 100.
8. Responsive design for mobile devices.

PROJECT FILES:
1. index.html - Website structure.
2. style.css - Website design and styling.
3. script.js - Calculations and conditions.
4. README.txt - Project information.

JAVASCRIPT CONCEPTS:

1. VARIABLES:
let is used for values that can change.
const is used for values that should not be reassigned.

2. DATA TYPES:
String is used for student name.
Number is used for subject marks.

3. OPERATORS:
+ is used to calculate total marks.
 / is used to calculate average.
* is used to calculate percentage.

4. CONDITIONS:
if, else if and else are used to
assign practice categories.

CATEGORY RULES:
80% or above = Excellent
60% to below 80% = Good
Below 60% = Needs Improvement

HOW TO RUN:
1. Open the project folder in VS Code.
2. Open index.html in a browser.
3. Enter student name.
4. Enter marks for all five subjects.
5. Click Calculate Result.
6. View the calculated result.

TECHNOLOGIES:
HTML5
CSS3
Vanilla JavaScript

NOTE:
These categories are for practice purposes only.
They are not official academic grades.
